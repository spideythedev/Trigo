01 / About

A little more about Trigo.

A JavaScript library built to make browser interactions easier to work with.

Trigo.js is a web interaction library designed to give developers a straightforward way to work with browser capabilities and visual effects. Instead of repeatedly building common interaction logic, developers can use Trigo.js as a single toolkit.

From device APIs and visual effects to canvas experiences and audio interactions, Trigo.js aims to make the browser a more expressive place to build.

The project is built with a focus on accessibility, simplicity, and practical developer experience.

02 / Getting started

How to use Trigo.js.

Get the package, include the library in your project, and start using its API.

01

Install with npm

Install the package in your project using your terminal.

TERMINAL 
npm install trigo.js
02

Use the CDN

Alternatively, include the hosted script directly in your HTML.

HTML 
<script src="https://cdn.jsdelivr.net/gh/spideythedev/Trigo@main/trigo.min.js"></script>
03

Work with the API

Use your Trigo instance to access the library's available methods.

JAVASCRIPT 
// Vibration
t.vibrate(200);

// Special vibration patterns
t.vibrate.heartbeat();
t.vibrate.sos();
04

Explore more methods

Here are a few examples of the available interaction APIs.

JAVASCRIPT 
// Canvas effect
t.confetti();

// Text-to-speech
t.speak("Hello from Trigo!");

// Fullscreen
t.fullscreen.enter();
Note: Browser APIs such as camera, microphone, location, notifications, and fullscreen may require HTTPS, user permission, or a direct user interaction. Availability also depends on the browser and device.

## Playground

Write and run Trigo.js code directly in the browser. Includes snippet buttons for quick experimentation.

```javascript
Trigo.confetti({ count: 80, spread: 120 });
Trigo.vibrate(200);
Trigo.notify('Hello!');
Trigo.fade.in('#element');
```
